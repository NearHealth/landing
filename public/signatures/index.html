Setup

How to add it

Gmail

  1. Click Copy signature on your card.
  2. Open Settings → See all settings → General → Signature.
  3. Paste it into the editor, then Save changes at the bottom.

Apple Mail

  1. Open Mail → Settings → Signatures and add a new one.
  2. Uncheck Always match my default message font.
  3. Paste the copied signature into the right-hand pane.

Outlook

  1. Open Settings → Mail → Compose and reply.
  2. Create a signature and paste the copied signature into it.
  3. If the image doesn’t paste, use Insert picture with the downloaded GIF.
